Original DEMIAND comparison woman — 2026-10-31

The body, clothing, fingers, footwear, face and hair geometry were authored from
zero for this project using parametric surfaces and independently sculpted mesh.
No third-party human, clothing or hair meshes are included.

Visual reference: the existing human-standing.webp image in this project.
The face colour is derived from that reference and projected onto original 3D
face/eye/lid geometry. This is a stylized approximation, not an exact scan.

The model has an upright neutral standing pose. Full width/height ratio is .271.
Viewer normalization measures actual exported geometry, sets the chosen height,
and places the lowest shoe point on the common floor. Source scene and build
recipe are included in the separately supplied original-model archive.
