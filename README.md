# DEMIAND — матрица размеров

Интерактивное сравнение 20 моделей техники DEMIAND с человеком.

[Открыть сайт](https://julia0613.github.io/matrix/)

Выберите приборы, укажите рост человека и высоту стола от 65 до 110 см. «Крупный план» приближает верхнюю часть фигуры и приборы в одном масштабе; «Общий вид» возвращает фигуру целиком. Фигуру можно двигать по горизонтали и ставить за выбранным прибором; ноги остаются на полу. «Контуры размеров» показывает ширину и высоту в общей шкале.

Каждое открытие начинается с DUOS 2100, RIVO 3500 и DeMixi 1200, роста 170 см, стола 76 см и масштаба 100%. Выбор не сохраняется и не передаётся между посетителями. Кнопка «Начать заново» восстанавливает пример.

Статический сайт: `index.html`, `style.css`, `app.js`, `catalog.js`, `assets`. Установка и сборка не требуются. Для локального просмотра откройте `index.html`. GitHub Pages публикует корень ветки `main`.

Габариты повторно проверены по доступным размерным схемам и характеристикам. Для GRANDEX 2900 и Chefmix 1300 пока используются значения исходной матрицы. NEGRONI 5000 исключён до подтверждения размеров. Фотографии сохраняют пропорции; анфас не передаёт глубину. Для точного размещения учитывайте зазоры по инструкции.
