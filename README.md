# DEMIAND — матрица размеров

Интерактивное сравнение размеров техники DEMIAND с человеком: выбор моделей, рост и положение человека, стол или пол, масштаб и карточки габаритов.

Статический сайт: `index.html`, `style.css`, `app.js`, `catalog.js` и папка `assets`. Установка и сборка не требуются.

Для локального просмотра откройте `index.html` в браузере. Для публикации через GitHub Pages выберите ветку `main` и папку `/ (root)`.

Сайт содержит 21 модель. NEGRONI DK-5000 пока доступен только в каталоге и карточке: габариты для масштабной сцены ещё не указаны.
